# Introduction

Backend Server for Messenger app using Node.js

Messenger app is also available on Android [Messenger Android](https://github.com/hoangmanhlong/messenger-android)

# Usage

To Start server please do the following steps:
1. Open Terminal => move to root project path
2. Run command below in Terminal

Production environment
```bash
npm run start
```
Development environment
```bash
npm run devStart
```
Test
```bash
node test.js
```
